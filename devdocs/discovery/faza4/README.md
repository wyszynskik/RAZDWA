# Discovery Faza 4 — T7–T10

- [T7 — EXPRESS per koszyk](T7-express-per-koszyk.md) — EXPRESS jest dziś naliczany wielokrotnie na poziomie pozycji i widoku, choć decyzja wymaga jednego końcowego mnożnika na sumie koszyka.
- [T8 — D-104 szablony etykiet](T8-d104-szablony-etykiet.md) — Zidentyfikowano osiem literałów `%`/brak klucza w szablonach i wyjaśniono mechanizm `hydrateRateLabels`, ale Z-06 nie występuje w repo.
- [T9 — tombstone wbudowanych](T9-tombstone-wbudowanych.md) — Dziś usuwanie jest fizyczne i nie rozróżnia wbudowanych od custom, a `visibleInCalculator: false` nie tworzy trwałego tombstone.
- [T10 — Dyplomy wpis cen per format i papier](T10-dyplomy-wpis-cen-format-papier.md) — Wpis jest rozproszony między warianty/podgrupy i punkty ilości, a pełny model jest blokowany brakiem zatwierdzonym ADR-H PR-17.
